## 这个网页做什么

1. **群聊**  
   挖矿圆桌、趋势讲席、今日圆桌、手艺现场、视觉工坊、生活补课、剧哦拍片组。

2. **朗读**  
   每条文字后面有「朗读」。标题栏可以一键从头读到尾，按说话人换声。没有按住说话。

3. **后台**  
   能看见现在有多少个群、多少条消息。提示词系统可以多选：
   - 多媒体（图片、图表库、表格、3D 引擎、讲席、公众号、新闻、链接、网页项目）
   - 调用哪些专业人员
   - 风格（现场 / 机制 / 口述 / 讲席 / 闲聊）

提示词写在这台浏览器里。

这是独立仓库，不塞进 A129 大库。人还是同一批：应见微、韩听澜、于白石、核桃油不黄……
